# אלגברה לינארית - חומר ונוסחאות

אתר לימוד עם כל החומר התיאורטי של הקורס, לפי שתי המצגות: **מספרים מרוכבים** ו**מטריצות**.
בכל נושא: הגדרות, משפטים ונוסחאות, הסבר במילים, דוגמאות מחושבות והוכחות (בתיבות מתקפלות), ודף נוסחאות מסכם בסוף כל חלק.

- `index.html` - האתר (קובץ יחיד)
- `source-map.md` - מיפוי בין סעיפי האתר לפרקי המצגות
